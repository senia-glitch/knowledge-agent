# Фактическое состояние первоначального запуска

Проверено 25 ноября 2026 года.

## Выполнено

- Запущен официальный готовый образ AnythingLLM 1.20.0; digest зафиксирован в `.env.example`.
- Compose и скрипты PowerShell прошли проверку синтаксиса.
- Локальные страницы приложения, настроек и русских подсказок отвечают HTTP 200.
- Создано рабочее пространство «Моя база знаний», режим Query.
- Загружен `knowledge/demo-school.txt` и завершена индексация: один документ.
- Встроенная модель `MintplexLabs/multilingual-e5-small` скачана и работает внутри контейнера.
- Реальный поиск в LanceDB возвращает фрагмент с ответом и источник для вопросов «Сколько длится занятие?» и «Сколько человек можно принять на один урок?».
- После перезапуска только контейнера этого проекта документ сохранился, оба запроса поиска снова прошли.
- Образ занимает около 1.19 ГБ по Docker image inspect. В одном замере после перезапуска контейнер потреблял около 377 МиБ RAM; это разовый замер без активной индексации, не максимальное потребление. Лимит RAM — 4 ГБ.
- Публичный список моделей OpenCode Go доступен по выбранному адресу. Запросы генерации без ключа не выполнялись.
- Пользователь сохранил ключ через интерфейс. Подключена модель `gpt-6-luna` через Generic OpenAI.
- Первый запрос был отклонён из-за отсутствия `x-opencode-session`. Исправлено штатным `GENERIC_OPEN_AI_CUSTOM_HEADERS`; код образа не менялся. После перезапуска Go принял запрос.
- Реальный ответ модели по базе: занятие длится 45 минут; в ответе указан источник, поток завершён без ошибки.
- На вопрос о стоимости модель ответила, что стоимость в документе не указана.
- На вопрос о личной жизни модель ответила, что таких сведений в загруженном документе нет; личные сведения не выдумывались.
- На общий вопрос об условиях модель перечислила известные условия с оговоркой и указанием отсутствующей стоимости. Отдельного уточняющего вопроса в этом примере не было.
- Демонстрационный документ временно заменён версией с длительностью 60 минут; после индексации в новом диалоге модель ответила 60 минут. Исходная версия с 45 минутами восстановлена в индексе.

## Границы результатов

Базовые сценарии проверены на одном небольшом вымышленном документе. Это не гарантия отсутствия ошибок на любых материалах. Контекстная неоднозначность не всегда вызывает уточняющий вопрос — в проверенном случае модель дала условное объяснение. В ответах через API присутствовали сведения об источнике; открытие ссылки пользователем в браузере не проверялось автоматически.

Автоматическая визуальная проверка браузера не выполнена: инструмент браузера завершался ошибкой запуска sandbox. Доступность страниц подтверждена HTTP-проверками; открытие вкладки настроек запрошено через Codex, наличие браузерной вкладки в правой панели подтверждено контекстом приложения.

## Ограничения

В папке `knowledge` нет автоматического наблюдения. Добавление/замена документов выполняется через интерфейс. Публичное размещение, пользовательские роли и генерация контента не проверялись в этом MVP.

Один постоянный заголовок Go используется для основной демонстрационной сессии приложения. Полноценная раздельная маршрутизация нескольких диалогов и пользователей требует дальнейшей интеграции.
