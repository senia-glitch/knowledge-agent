# Проверка MVP

Для реальной приёмки требуется действующий ключ провайдера. Проверка заглушкой не доказывает качество LLM.

Загрузить `knowledge/demo-school.txt` в базу рабочего пространства и дождаться индексации. Выбрать Query, температуру 0.1, порог сходства No restriction для первоначального поиска. Инструкции помощника — в README.

| Вопрос / действие | Ожидаемый результат |
|---|---|
| Сколько длится занятие? | 45 минут; ссылка ведёт к demo-school |
| Сколько человек можно принять на один урок? | Не более 12; проверяем поиск по перефразированному вопросу |
| В какие дни и во сколько проходят занятия? | Вторник и четверг, 18:30 |
| Сколько стоит занятие? | Стоимость не указана в материалах; цена не придумана |
| Расскажи про условия | Уточнение, какие условия интересуют, или пояснение нескольких известных условий без выдумок |
| Изменить длительность в исходном файле на 60, удалить старую версию из workspace и загрузить новую | В новом чате ответ 60 минут, ссылка на новую версию |
| Остановить и запустить проект | Документы и настройки сохранились |

Фиксировать фактические ответы и ссылки. При ошибке отдельно проверить найденные отрывки и вывод модели. Возвратить исходный демонстрационный файл к 45 минутам после проверки обновления.
