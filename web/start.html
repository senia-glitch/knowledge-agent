Помощник по твоим документам

Четыре шага до первого ответа. Настройки и ключ вводятся в самом AnythingLLM. Эта страница не принимает и не хранит ключи.

Проверяем доступность приложения…

1. Подключи модель

Открой настройки модели. При первом запуске приложение может предложить свой мастер: пройди его, затем вернись сюда.

Для OpenCode Go выбери OpenAI (Generic). Получи API-ключ в OpenCode Console и вставь в поле API Key. Подключение использует официальный API без маскировки клиента.

Base URL:https://opencode.ai/inference/go/openai/v1

Адрес провайдера проверяется при настройке. Если актуальная документация Console указывает другой адрес Go API, используй его.

Model: выбери доступную по подписке текстовую модель из списка. Если нужен ручной ввод, скопируй точный идентификатор из Console. Начни с контекста 8192 и максимального ответа 1024 токена; эти значения можно изменить позже в пределах модели.

Нажми сохранение. Для другого провайдера поменяй адрес, ключ и модель либо выбери его встроенный профиль.

Открыть настройки модели ↗

2. Проверь индексацию

В разделе Embedding выбери AnythingLLM Embedder / Native и multilingual-e5-small. Это небольшая модель для поиска по русскому тексту, она работает внутри контейнера и не генерирует ответы. При первой индексации скачиваются её файлы; это может занять несколько минут.

Хранилище векторов — LanceDB. Менять модель индексации после загрузки документов следует с повторным построением индекса.

Открыть настройки индексации ↗

3. Добавь знания

  1. Открой приложение и создай рабочее пространство, например «Моя база».
  2. В управлении документами загрузи knowledge/demo-school.txt из папки проекта.
  3. Добавь документ в рабочее пространство и нажми Save and Embed либо аналогичную кнопку индексации. Дождись завершения.
  4. В настройках чата рабочего пространства выбери Query, температуру 0.1. В настройках векторного поиска для первой проверки — No restriction.
  5. Установи инструкцию ниже в поле System Prompt рабочего пространства.

Открыть приложение ↗

Файл в папке knowledge сам по себе ещё не попадает в базу. В этом MVP загрузка и обновление выполняются через интерфейс.

4. Получи первый ответ

  • «Сколько длится занятие?» → 45 минут, с источником.
  • «Сколько человек можно принять на один урок?» → 12 человек.
  • «Сколько стоит занятие?» → В материалах стоимость не указана.

Проверь ссылки: они должны вести к загруженному документу. Зелёный статус приложения наверху подтверждает только его доступность; подключение модели и качество ответов проверяются этими вопросами.

Это локальный MVP. При ошибке ключа проверь ключ и подписку; при превышении лимита дождись его обновления; при сетевой ошибке проверь доступ из Docker через своё подключение. Повторные бесконечные запросы не нужны.
